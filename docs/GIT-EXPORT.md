# Git 导出说明

本目录是独立源码副本，可作为 Git 仓库根目录。已排除原 Git 历史、依赖、编译产物、EXE、运行数据、桌面截图、日志、测试输出、本机调试配置和编辑器设置。原项目的源码、运行数据及运行版未改动。

源码、两份依赖锁文件、构建配置、必要图像素材、通用测试和说明文档已保留。原文档中的本机运行历史、实际板子位置、资料摘要和本机发布记录已从此副本移除。鲸鱼样式的显示名称为“用户”。

## 隐私与凭证检查

已对全部导出文件执行离线规则扫描和关键词复核，覆盖 API Key、访问/刷新 Token、Cookie、数据库连接密码、OAuth client secret、云密钥、私钥、JWT、带凭证的 URL 与高熵字符串。同时检查个人用户路径、邮箱、手机号、身份证号和内网地址。

二进制素材检查了可读字符串和 PNG/ICO/ICNS 元数据。三张书签图片不含文本或身份元数据；应用图标只含透明度/尺寸信息。PDF 是人工构造的通用预览测试样本，没有作者或设备信息。没有包含用户提供的整张桌面截图。

扫描未发现实际凭证或个人标识。文件名中的 `@` 和 Rust 的公开功能名称经复核为误报。详细计数见 [扫描报告](EXPORT-SCAN.json)。报告仅记录相对路径和扫描结果，不含原用户路径、匹配到的值或运行数据。

`.gitignore` 已补充本地环境文件、账户配置、凭证文件、私钥、数据库及运行资料的忽略规则。以后添加新文件时，仍应检查暂存内容；忽略规则不影响已经提交的文件。

## 保存到 Git

在本目录打开终端，再执行：

```powershell
git init
git add .
git diff --cached --stat
git commit -m "Initial source snapshot"
```

本次没有创建提交、配置远程地址或推送。将这个目录作为上传范围，原工作目录中的运行资料与截图继续留在本机。
